# 控制台字体

控制台自带的拉丁字符子集（woff2），中文仍使用系统字体。随项目分发，不从外部 CDN 加载：控制台的内容安全策略只允许本站资源，生产服务器访问 Google Fonts 也不稳定。

| 文件 | 字体 | 用途 | 许可证 |
|---|---|---|---|
| `inter-latin.woff2` | Inter（可变字重 400–700） | 界面文字、小号数字 | `OFL-inter.txt` |
| `dm-serif-display-latin.woff2` | DM Serif Display | 大号数字 | `OFL-dm-serif-display.txt` |
| `bricolage-grotesque-latin.woff2` | Bricolage Grotesque 800 | Logo 字样 | `OFL-bricolage-grotesque.txt` |

三款字体均采用 SIL Open Font License 1.1，文件取自 Google Fonts 的 latin 子集。
