# Dustoff 前端重新设计提案

日期：2026-09-17。状态：设计评审稿，尚未实施到正式前端。

本轮先查看本机控制台的七个页面及现有前端源码，再重新安排入口和内容。保留用户认可的结果浏览布局，其他页面按使用目的重新组合。本目录的所有数据、标题、作者、时间、地址均用于示意，不应视为当前运行状态或真实配置。

## 整体建议

主入口收为「结果浏览、收藏、运行、设置」。打开控制台默认进入结果浏览；运行是按需查看的后台任务区域；账号和模型等低频配置放在设置。采用温和浅色底、绿色强调、细分隔线和紧凑表单，减少大面积卡片与重复说明。

| 现有位置 | 建议的新位置 | 变化与理由 |
| --- | --- | --- |
| 总览的最近笔记 | 结果浏览，作为默认首页 | 直接使用产物，减少重复的笔记入口 |
| 总览的今日额度、待办、运行状态 | 运行 → 待处理 | 和开始本轮、任务进度放在一起 |
| 总览的下次定时 | 侧栏底部状态、运行 → 自动安排 | 日常轻量可见，编辑时再展开 |
| 作品账本 | 收藏 | 保留用途、真实视频状态、处理结果三者并列 |
| 独立作品详情 | 收藏列表侧边详情 | 查看或修改用途后仍能回到原列表上下文 |
| 结果浏览 | 结果浏览 | 保留左侧列表、右侧正文，以及笔记/原始转写切换 |
| 运行与定时 | 运行 → 待处理、自动安排 | 手动参数通过「开始一轮」弹层展开 |
| 运行日志 | 运行 → 运行记录 | 先展示本轮结果和时间线，原始日志和 JSON 折叠 |
| 登录管理、设置中的登录内容 | 设置 → 账号连接 | 一个位置管理登录、有效期、检查和提醒 |
| 模型与密钥、转写热词 | 设置 → 模型服务 | 按用途判断、语音转写、笔记整理三个步骤组织 |
| 文件位置、空间和日志保留限制 | 设置 → 文件与空间 | 按文件用途展示，路径和限制按需编辑 |
| 其余处理策略 | 设置 → 处理规则 | 每日数量、时长、通知在前，高级参数折叠 |

不再保留独立总览的代价是少了一张集中显示全部统计的页面；当前建议优先减少一次进入阅读前的跳转。若后续实际使用以运行监控为主，可以把默认入口改成运行，而不必重新增加总览。

## 逐页效果图

### 01 · 结果浏览

### 02 · 收藏

直接看到建议是否已应用、视频是否保留、原结果是否仍在。失败与待确认有直接入口。

![收藏](02-collection.png)

### 03 · 收藏详情

在侧边修改用途，保留列表上下文。建议与原有结果明确区分，保存后加入下一轮待办。

![收藏详情](03-collection-detail.png)

### 04 · 运行：待处理

![运行待处理](04-run.png)

### 05 · 运行：自动安排

左侧编辑起始时间与间隔，右侧预览下一次与之后的安排。

![自动安排](05-schedule.png)

### 06 · 运行：运行记录

左侧按轮次切换，右侧先读结果与时间线，再按需展开业务、定时和控制台日志。

![运行记录](06-history.png)

### 07 · 设置：账号连接

凭据到期估算与在线可用性分开表达；保留立即检查与官方登录流程。

![账号连接](07-account.png)

### 08 · 设置：模型服务

按用途判断、语音转写、笔记整理三个实际处理步骤组织配置。热词、超时、思考档位与输出上限位于高级区域。

![模型服务](08-models.png)

### 09 · 设置：文件与空间

笔记、收藏视频、临时媒体、账本和日志分别展示保存目的与保留方式；目录与空间限制在同页编辑。

![文件与空间](09-storage.png)

### 10 · 设置：处理规则

日常限制优先，收藏用途说明就近展示，扫描窗口和整轮时限折叠。

![处理规则](10-rules.png)

### 11 · 手动运行弹层

默认执行正常流程；「只继续已有待办」收进高级选项。

![手动运行](11-manual-run.png)
