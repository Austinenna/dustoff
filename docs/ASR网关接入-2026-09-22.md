# ASR 接入本机网关

2026-09-22：正式 ASR 已切换到本机 AI 网关，使用已有 Dustoff 项目 Token 和已获授权的 `qwen-asr`。当前上游仍为 `qwen-audio-3.0-asr-flash`；变化在调用入口和凭据管理。

## 配置与行为

- `DUST_ASR_BASE=http://127.0.0.1:8317/v1/asr/transcriptions`，填写完整接口地址。
- `DUST_ASR_MODEL=qwen-asr`。
- `DUST_ASR_KEY` 保存项目 Token，仅在本机私有配置中，不进入仓库；界面不回显。
- 保持 DashScope 原生 JSON 格式，保留热词、290 秒切片、语种、逐词时间戳和原有重试规则。按响应结构解析，不依赖网关别名等于上游模型名。
- 兼容原直连：未设置接口地址时沿用百炼官方端点；只有该端点允许回退到旧 `DUST_DASHSCOPE_KEY`。网关缺少项目 Token 时不会误用百炼 Key。
- 设置 → 模型服务 → 语音转写可修改接口、模型及密钥；旧百炼密钥留在高级直连配置中。
- 新配置用于下一轮转写，既有 TXT、时间戳与笔记不重跑。用途判断、笔记模型及定时安排沿用原值。

## 验证

- 当前网关模型列表包含 `qwen-asr`，Dustoff 项目状态为 `active`。
- 约 7 秒本地合成中文语音，经网关返回完整文本和 16 个词级时间戳。
- 使用正式 ASR 配置在隔离临时目录执行 `transcribeOne`：从视频提取音轨、请求网关、写入 TXT 与 `.words.json`、清理临时音频均通过，保留测试源视频。未改动正式收藏账本。
- 协议、配置、三类处理、模型设置和控制台相关测试共 38 项通过；工作区已有阅读页另外 3 项回归通过。覆盖错误格式、无人声、授权失败、限流、缺失凭据、密钥隔离和配置脱敏。
- 浏览器确认设置页显示网关接口、`qwen-asr` 和已配置的密钥状态。
- 正式配置更新前已保存私有备份，配置和备份权限均为 `0600`。空闲时重新加载控制台，定时加载状态、起点、间隔、下次时间和累计运行次数保持不变。
