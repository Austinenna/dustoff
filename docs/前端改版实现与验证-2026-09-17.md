# 紧凑前端改版 · 2026-09-17

已将确认的紧凑设计接到真实业务，入口仍为 `http://127.0.0.1:47831`，或双击项目的 `打开控制台.command`。后续新增总览作为默认首页，笔记和视频独立浏览。

| 主入口 | 内容与操作 |
| --- | --- |
| 总览 | 真实笔记、保留视频、待办数量；最近笔记与视频；自动安排、运行入口和待确认 / 失败提示。 |
| 笔记 | 搜索、分页、笔记 / 仅文字稿筛选；左列表右正文；原稿切换、Obsidian、本地文件夹和原视频入口。窄屏先选列表，再进入正文；旧 `#results` 链接继续可用。 |
| 视频 | 独立搜索与分页、真实本地封面；点卡片页内播放，支持原生暂停、进度、音量和全屏。包含同时提取笔记的作品，排除已清理视频与口播转写临时缓存。 |
| 收藏 | 用途与未应用建议、视频现状、已有结果并列展示；支持状态筛选、搜索和分页；侧栏查看详情、保存用途、恢复失败待办。 |
| 运行 | 实际队列、今日额度和笔记数；手动运行与停止；自动安排的起始时间、重复间隔及三次预览；运行记录先展示结果和日志中的节点，再展开完整日志。 |
| 设置 | 账号连接、模型服务、文件与空间、处理规则。所有 25 个原有可编辑配置均有入口。密钥不回显，留空保留。 |

移除独立面包屑和大标题副文案，标题、数量、操作在一行内。1280 像素桌面下，阅读区从顶部 65 像素开始。操作反馈以浮动提示呈现，不把内容向下挤。账号信息轮询不重建配置表单，保留尚未保存的输入。

后续按用户反馈恢复结果浏览的原版字体排版：桌面文章标题 30px / 500、正文 14px / 1.9 行高、列表标题 14px / 500，采用原字体栈和近黑色文字。正文段落和分级标题间距同步恢复；紧凑顶部、导航与页面结构保留。浏览器核对 1280px 桌面和 390px 窄屏均生效，窄屏文章标题为 25px，无整页横向溢出。

## 实现边界

- 新入口为 `web/studio.html`，配套 `studio.mjs`、`studio-view.mjs`、`studio.css`；复用已有 Markdown 渲染、登录进度组件和定时计划计算。无新增依赖。
- `console.mjs` 仅允许明确列出的前端资源，保留 loopback、Host、Origin、CSRF 和 CSP 防护。新增只读 `/api/queue`，筛选和顺序与真实日常队列一致，最多返回 10 条，不发送下载元数据。
- 处理流程、用途规则和定时器执行机制继续使用已有业务入口。正式数据没有通过验收操作触发下载、重跑或配置变更。
- 视频流只接受账本作品 ID，复用原有文件校验，不接受任意路径；支持 GET / HEAD、单段 Range 和 416 响应。已清理、缺失的原文件不能通过缓存继续打开。
- 优先播放本地原视频，浏览器报告播放失败时自动准备 H.264 / AAC 副本，也可手动切换兼容播放；原文件不改写、不上传。兼容副本最长边 1280 像素，完成后下次打开直接复用。转码只同时运行一个，封面串行生成，页面关闭后停止播放。
- 封面与播放副本位于 `~/.dustoff/console/media-preview`，512 MiB 缓存预算，生成前回收旧缓存并遵守最低可用空间规则；只回收本功能的普通缓存文件。原文件尺寸或修改时间变化后缓存失效。生成需要已安装的 ffmpeg，失败时可用外部播放器。设置的文件与空间页显示缓存占用。
- 开始时已有的 `web/app.js`、`web/index.html`、`web/style.css` 和 `docs/控制台使用说明.md` 未提交修改逐字节保留。新版入口不加载这些旧页面文件；本次提交不包含它们。
