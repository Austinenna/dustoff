# 核心观点
高级感纸艺拼贴动画不必在 AE 里逐帧手拖，用开源 skill 配合 Codex 等 agent，可以按「拆解文案 → 生成分镜与视频提示词 → 生成式平台出片」三步一键直出。

## 适用场景
- 适合口播视频赛道：AI 工具、知识科普、商业财经、历史文化等。

## 三大步骤

### 1. 拆解文案、规划视觉
- 把文案和 skill 一起喂给 Codex 或其他 agent，自动拆解文案并输出视觉逻辑规划方案。
- agent 会判断内容结构：
  - 只表达一个观点 → 设计成 4~6 秒的单次视觉冲击；
  - 讲过程或因果关系 → 拆成 3~5 个连续状态，构成完整的视觉证据链。

### 2. 生成分镜提示词与视频提示词
- skill 分别为每张分镜图编写生成提示词，锁定主体、构图、纸张、色彩等连续性元素，再编排动画。
- 这一步的目的：把抽象文案转化成画面逻辑，降低观众理解难度。
- 生图直接用 Codex 内置的生图模型。

### 3. 生成成片
- 把分镜图和视频提示词一起复制到视频生成平台，按画布生视频即可。
- 视频生成工具不限，作者用的是 Lava；模型推荐 MiniMax，效果较好。

## 结论
整套流程把原本需要 AE 手工逐帧制作的纸艺拼贴动画，压缩成「文案进、成片出」的自动化管线，核心价值在于 skill 承担了文案拆解、视觉结构规划和提示词编写的全部中间环节。
