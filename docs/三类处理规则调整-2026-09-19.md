# 三类处理规则调整与验证

## 当前规则

收藏只有三个互斥的处理类型，另保留“待确认”状态：

| 类型 | 判断依据 | 处理结果 |
|---|---|---|
| 知识笔记（note） | 讲解、访谈、教学等，可主要通过语音整理 | 低画质有声素材 → ASR → 知识笔记 |
| 视频（video） | 观看、原声欣赏，或明确依赖画面而不能通过语音整理 | 高清原声视频；不进入转写、笔记流程 |
| 图集（gallery） | 平台媒体格式为图集 | 按顺序下载全部图片；不调用分类、ASR、笔记模型 |
| 待确认（review） | 元数据不足或线索矛盾 | 暂不下载，用户选择知识笔记或视频后继续 |

模型只读取标题、作者、时长等元数据，不观看视频。标题出现 PPT、代码或操作演示不自动成为单独的“画面知识”；有明确讲解线索可以归为知识笔记，纯画面内容归为视频，判断不了则待确认。不再接受 speech、visual、both 作为新分类。

## 流程与文件边界

- 转写、笔记入口只接受知识笔记；图集直接进入图片下载，视频下载完成即结束。
- 知识笔记、视频、图集结果列表按当前处理类型区分。手动改类型保留已有文件与历史成果，旧文件可在收藏详情查看，不让旧产物导致结果列表串类。
- 每类分别累计连续失败，三次只暂停这一类，本轮继续其他类型。用途模型错误单独累计，不阻塞已分类条目或图集。
- 某类媒体容量不足只暂停该类型；实际共用的收藏空间耗尽仍会同时限制视频和图集。每日总额度、最低磁盘空闲和整轮时限仍为公共限制。
- 知识笔记成稿、文字可靠且无缺料标记后，才允许清理其临时视频；未成稿或文字不足保留素材。缺项用 retain_media 记录，当前不创建 OCR 待办。旧 needs_ocr 字段保留兼容与保护旧素材。
- 旧收藏目录中的视频可被知识笔记流程读取复用，但不会被自动清理。修复了此前只允许读取临时缓存目录、导致已下载的画面知识记录连续失败的问题。
