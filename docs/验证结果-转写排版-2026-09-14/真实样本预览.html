核心观点

高级感的纸艺拼贴动画不必在 AE 里逐帧手拖，用一个 Agent（如 Codex）加上作者开源的 Skill 即可一键直出同款效果，适合 AI 工具、知识科普、商业财经、历史文化等口播视频赛道。

工作流三大步骤

第一步：拆解文案、规划视觉内容

  • 把文案复制下来，连同开源 Skill 一起喂给 Codex 或其他 Agent，自动拆解文案并做视觉逻辑规划。
  • Agent 会根据内容类型选择结构：
    • 单个观点 → 设计成 4~6 秒的单次视觉冲击；
    • 过程/因果关系 → 拆成 3~5 个连续状态，构成完整的视觉证据链。
  • 这一步的目的是把抽象文案转化为画面逻辑，降低观众理解难度。

第二步：生成分镜提示词和视频提示词

  • Skill 会为每张分镜图编写生成提示词，锁定主体、构图、纸张、色彩等连续性元素，保证风格统一，最后再编排动画。
  • 作者生图直接用 Codex 内置的生图模型，分镜图生成后再生成视频提示词。

第三步：生成式平台出成片

  • 把分镜图和视频提示词一起复制到视频生成软件（作者用的是 Lava，工具不限，按喜好选择）。
  • 视频模型推荐 MiniMax H3，效果较好；之后直接图生视频即可。

结论

整个流程 = Skill 拆解规划 + Agent 生成分镜/视频提示词 + 生成式平台出片，三步即可把口播文案批量转成纸艺拼贴风格的动画，替代传统 AE 逐帧制作。具体 Skill 地址作者放在粉丝群置顶。
