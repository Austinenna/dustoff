# dustoff — 抖音视频知识库

> ⚠️ **已归档，不要照着做。** 这是 whisper 时代的一份 Claude Skill：靠对话触发、
> Claude 亲手跑 `fetch.mjs` 再亲手写文件。现在整条链路是脚本，转写换成了云端
> qwen，输入来自账本。**笔记格式以 [`第三段-笔记规格.md`](第三段-笔记规格.md) 为准**，
> 那份文档末尾列了相对本文改了哪些、为什么。
>
> 本文保留是因为它记着两件仍然成立的事：CDP 截包取真实地址的原理（下面「原理」一节），
> 以及笔记正文「核心观点／分论点／结论」这个骨架——那部分原样活了下来。

把抖音视频转成可检索的知识笔记。核心流程：**取真实地址 → 下载 → 转写 → 提炼成笔记**。

## 原理（为什么这么做）

抖音页面用 blob 流播放，视频真实地址藏在带签名的 CDN 链接里，签名由前端 JS 实时生成，自己逆向很脆弱。`yt-dlp` 直连目前被风控拦截（报 `Fresh cookies needed`）。

本 skill 的破局点：**不对抗签名，而是让真实浏览器替我们签名**。脚本启动系统 headless Chrome 打开视频页，用 CDP（Chrome DevTools Protocol）截获页面自己发出的 `aweme/v1/web/aweme/detail` 接口响应体——里面就有元数据和真实 CDN 直链。零 npm 依赖（Node ≥ 21 自带 WebSocket）。

> ⚠️ CDN 直链含时效签名（约数小时）。脚本是「取址→下载」连贯执行的，正常无需关心；但若手动拿到地址隔天再下会失败。

## 依赖（均已在本机就绪）

- `node` (≥21，自带全局 WebSocket)
- Google Chrome（`/Applications/Google Chrome.app`）
- `ffmpeg`、`whisper`（openai-whisper）、`curl`

## 用法

### 单个视频

跑流水线脚本，它会下载+转写并把结果（含文字稿）以 JSON 打到 stdout：

```bash
node ~/Documents/dustoff/scripts/fetch.mjs '<抖音链接>' [whisper模型]
```

- `<抖音链接>`：支持 `https://v.douyin.com/xxxx/` 短链、`https://www.douyin.com/video/<id>`、含 `modal_id=` 的收藏页链接。
- `[whisper模型]`：可选，默认 `base`。`tiny`/`base` 快，`small`/`medium` 更准更慢。口播清晰用 `base` 即可；专业术语多、想要更准可用 `small`。

脚本 stdout 输出单行 JSON，关键字段：`aweme_id` `desc` `author` `create_time`(unix秒) `duration_s` `source_url` `dir` `transcript_path` `transcript`(完整文字稿)。进度日志走 stderr。

中间产物缓存在 `~/VideoKB/.cache/<aweme_id>/`（video.mp4 / audio.wav / transcript.txt / meta.json），重复跑同一视频会命中缓存、跳过已完成步骤。

### 只取元数据/地址（不下载）

```bash
node ~/Documents/dustoff/scripts/get_meta.mjs '<抖音链接>'
```

## Claude 的工作流程

1. **确认链接**。用户给一个或多个抖音链接。多个则逐个处理。

2. **跑 fetch.mjs**。对每个链接执行上面的命令，timeout 设足够长（whisper base 处理 4 分钟视频约需 1–2 分钟，更大模型更久；建议 timeout ≥ 600000ms）。从 stdout 解析 JSON，拿到 `desc`/`author`/`create_time`/`duration_s`/`transcript`。

3. **提炼成笔记**。**这是 skill 的灵魂，不能跳过**。whisper 的中文转写会有同音/专名错误（如把 Anthropic 听成「NZROPIC」、OpenClaw 听成「OpenCloud」、context 听成「康text」），你要：
   - 结合视频标题 `desc` 里的 hashtag 和上下文，**纠正明显的专名/术语错误**；
   - 把口语流水账重组成**结构化要点**（核心观点 / 分论点 / 关键数据 / 结论），而非逐字复述；
   - 保留有信息量的金句和具体数字、人名、产品名。

4. **写入知识库**。存到 `~/VideoKB/`，文件名格式：
   `YYYY-MM-DD-<简短主题>.md`（日期用视频发布日 `create_time`，非今天）。
   用下面的笔记模板。写完后向用户报告：标题、一句话核心、文件路径。

### 笔记模板

```markdown
---
标题: <凝练的主题标题>
来源: 抖音
作者: <author>
视频ID: <aweme_id>
链接: https://www.douyin.com/video/<aweme_id>
发布日期: <create_time 转成 YYYY-MM-DD>
时长: <duration_s 转成 X分X秒>
收录日期: <今天 YYYY-MM-DD>
标签: [<3-6 个主题标签>]
---

# 核心观点

<2-4 句话讲清这个视频到底说了什么、最有价值的点是什么>

## <分论点小标题>

<结构化要点，可用列表/表格。纠正过转写错误后的准确内容>

## 结论

<视频的落脚点 / 给观众的 takeaway>
```

## 批量场景

用户说「把这几个视频都整理了」→ 依次对每个链接跑 fetch.mjs（串行即可，whisper 占 CPU），各自生成一篇笔记，最后给一个汇总清单（标题 + 路径 + 一句话）。

## 关于「自动读取收藏夹」

抖音收藏夹页（`douyin.com/user/self`）需要登录态，headless 干净会话拿不到。当前 skill 的输入是**用户主动给的链接**。若用户想要全自动抓收藏夹，需要在一个持久化的浏览器 profile 里登录抖音后再扩展——这超出本 skill 范围，遇到此需求时如实告知用户，并建议「攒一批链接发给我批量处理」的省事方案。

## 故障排查

- `未截获 aweme/detail 响应`：视频可能已删除/设为私密；或抖音页面结构变更。先用浏览器确认链接可正常打开。
- `所有 CDN 地址下载失败`：签名过期（极少见，因取址和下载是连贯的），直接重跑即可。
- `缺少依赖 xxx`：安装对应工具（`brew install ffmpeg`；`pip install openai-whisper`）。
- Chrome 路径不同：设环境变量 `DUST_CHROME=/path/to/chrome`。
